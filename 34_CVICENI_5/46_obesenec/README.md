
# (46) Oběšenec

> `"", [], txt`


V textovém souboru obesenec.txt je na každém řádku zapsáno jedno slovo. Ve hře Oběšenec je úkolem hráče postupně hádat písmena, která se nacházejí v hádaném slově.

Ukázka textového souboru se zadanými slovy:

```
kniha
hudba
film
kino
divadlo
koncert
```

Vytvořte program - hru Oběšenec (v textovém režimu) s vlastnostmi:

- Program přečte všechna slovíčka ze souboru do paměti, jedno z nich náhodně vybere a hráč ho bude hádat.
- Namísto hádaného slova se vypíše přilušející počet teček a hráč je vyzván k hádání písmen.
- Když hráč uhodne písmeno, program ho na příslušné pozici slova zobrazí (zatím neuhádnutá písmena jsou vypsána tečkou).
- Hráč může neuhádnout maximálně 10 písmen, tehdy hra končí a program vypíše hráči, že neuspěl.
- Pokud hráč uhodl celé slovo (postupně), hra končí gratulací.

Otázky:

1. Co se stane, když je vstupní soubor prázdný?
2. Co se stane, je-li v souboru namísto jednotlivých slov slovní spojení?
3. Co se stane, když na vstupu zadá uživatel více písmen?
