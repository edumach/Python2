
# (5) Školní jídelna

> `"", {}, txt`

V textovém souboru `jidla.txt` jsou uloženy informace o objednaných jídlech ve školní jídelně jednotlivými strávníky na následující den. Informace o jednom výběru strávníka je v jednom řádku. Řádek obsahuje číselný kód strávníka, který je oddělen mezerou od objednaného jídla. Výběr jídla reprezentuje jeden znak označující barevné označení jídla (`z` – zelená, `c` – červená, `m` – modrá, `o` – oranžová). Vytvořte program, který:

- z textového souboru zjistí celkový počet objednaných jídel,
- spočítá počet jednotlivých jídel a vypíše jejich počty (jednotlivé barvy zvlášť),
- zjistí, zda si některé jídlo (jídla) objednalo méně než 20 lidí, a vypíše jejich barevný kód (jejich označení), 
- pokud si každé jídlo objednalo dostatek strávníků, vypíše nám o tom program informaci.

Ukázka textového souboru:

```
142 o
362 c
368 c
289 m
356 c
70 o
...
```

Otázky:

1. Co udělá vaše řešení úlohy, pokud je vstupem soubor bez některého jídla?
2. Jak bychom měli upravit vaše řešení úkolu, abychom mohli vyhodnotit i jiná označení jídel (při rozšíření nabídky)?
