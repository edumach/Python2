
# Lekce 20: Kontrolní cvičení

Kontrolní cvičení bude v rozsahu 90 minut. Přehled požadovaných programových konstrukcí

- Okno tkinter s parametry (rozměry, barva)
- Kreslení tvarů a textu (obdélník, kruh, text)
- Použití barev (obrys, výplň)
- Běžné typy proměnných (číslo, text)
- Základní matemetické operace (`+ - * /`)
- Práce s náhodnými hodnotami (`random`)
- Cykly (`for`)
- Časovač (`after`)
- Podmíněné příkazy (`if`, `elif`, `else`)
- Porovnávání hodnot a logické operátory
- Vlastní funkce (definice, volání, parametry)
- Vstup a výstup (textové pole, tlačítka)
- Převod vstupu na číslo (`int`)
- Práce se stavem programu (události)
- Přesun objektu (`move`, `tags`)
