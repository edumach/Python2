
# (21) Zpřeházený text 1

> `"", [], txt`

Výzkumy ukázaly jednu zajímavou věc. Člověk dokáže přečíst slova i bez toho, aby jednotlivá písmena dávala smysl. Je to způsobeno tím, že mozek čte slova jako celek, ne po jednotlivých písmenech. Stačí, aby bylo první a poslední písmeno na stejném místě, tak jako v klasickém slově. Anglicky se to nazývá *Scrambled text*.

V textovém souboru `zprehazeny_text.txt` je připraven vstupní soubor. Vytvořte program, který:

- přečte a vypíše textový soubor,
- v textu identifikuje jednotlivá slova (předpokládejme, že text obsahuje pouze slova a mezery, a žádné jiné znaky neobsahuje),
- ve slově náhodně zpřehazuje písmena, kromě prvního a posledního písmene,
- takto transformovaný text vypíše na obrazovku,
- takto transformovaný text uloží do textového souboru vystup.txt.

Ukázka vstupního textového souboru:

```
Výzkumy prozradily jednu zajímavou věc
Člověk dokáže přečíst slova i bez toho
aby jednotlivá písmena dávala smysl
```

Ukázka výstupního textového souboru:

```
Vumzýky pirozldray jednu zmíoaajvu věc
Čoěvlk doákže pčíesřt solva ii bez thoo
aby jovnitedlá penímsa davála ssyml
```

Otázky:

1. Pokud by text obsahoval i interpunkční znaménka, jak by to ovlivnilo řešení úlohy?
2. Která slova se nebudou jevit jako zpřeházená ve výstupním textu?
